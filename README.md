# Convolutional Neural Network (CNN)

## Overview
This repository provides the user with an easy and simple way of designing a CNN.
It allows the user to specify:
- number of convolutional layers
- convolutional kernels per each layer
- pooling layers and type of pooling
- feed-forward layers
  - neurons per layer
  - activation function per layer
- type of optimization and learning rate
- loss function

For training, the user can also specify the batch size and number of epochs.

Using these building blocks, the user can easily configure the CNN as needed.
